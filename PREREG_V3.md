# BrahSol v3 confirmation plan — frozen after pilot, before confirmation

**Status:** *exploratory pilot already performed* on synthetic test seeds 0–299 and 10000–10079, trying 3–7 queries and observation noise 0.008–0.04. This is **not** a preregistration of that pilot. The confirmation cohort is **seeds 20000–20399**, never used in policy selection or pilot evaluations. The stopping threshold is selected solely on training seeds 5000–5099. The dynamics, hypothesis set, action masks, query budget, noise, and pass criteria are frozen here before running that cohort.

Model: 8 possible hidden labels, represented by 3 external pulses on exactly one of 8 TM-like routes at ticks 0/2/4. Each route has facilitation utilization u and depression resources r; the actual hidden label is never revealed to the controller. Query occurs after a fixed initial delay, every 3 time ticks, as a selected set of 4 routes; sensor observes **only the scalar SUM** of those route's noisy released amplitudes. Noise is Gaussian sigma=0.012 at the scalar readout. All query policies are given 5 slots, identical stimulation budget per chosen read (4 routes per query).

## Frozen confirmation gates

- **R0 physical read-backaction:** With a single fixed final diagnostic at tick 100, compare 0/1/3/5/8/12 earlier global pings at ticks 50,52,...; baseline and intervention have exactly matched elapsed time. Prediction: the linear trace-residue model's final class contrast is invariant to earlier broadcast reads to numerical precision; TM-like facilitation/depression contrast after 12 reads is <0.1 of no-extra-read control. Also report hidden-state separations and 8-way ideal-Gaussian-template accuracy, calibrating measurement noise separately to each model's no-extra-read contrast. The noise normalization makes cross-model *ratios* comparable, not raw amplitudes.
- **R1 addressability:** Confirm 8-way classification with one SUM sensor under 5 queries. Compare global broadcast, random 4-of-8 subsets, fixed 3-bit subset code repeated, and greedy model-based expected information gain over all 70 4-of-8 masks. Explicitly report both fixed and random as strong baselines, not just global. Prediction: global is at chance, selective policies exceed chance; active beats random in accuracy but need not beat fixed. The action selector knows the synthetic TM equations and candidate template states: it is an **oracle**, not a learned neural controller.
- **R2 efference-copy diagnostic:** Record identical random-subset sequences and noisy returns; decode each using exact action history, last 2, last 1, or zero earlier masks in the observer's predictive model. Prediction: retaining exact history improves decoding compared with zero retained masks. This is **a truncated-model ablation**, not a claim that an optimal no-history observer could never recover the class by marginalizing unknown action histories or learning a more sophisticated inference strategy.
- **R3 reward-trained reading-stop policy:** Search thresholds 0.5/0.65/0.8/0.9/0.95/1.0 on training seeds only for each policy. At test, stop querying when posterior confidence exceeds its frozen threshold, else query as its policy dictates. Reward=classification correctness - 0.025 per read. Compare trained stop rules to always-five-query strategy, random, fixed and global. Prediction: active typically saves reads while retaining classification skill. No claim of optimality or of a controller learning the medium's physics.

**Statistical reporting:** 400 independent synthetic seeds. Report absolute accuracies and paired differences, not significance against biological data. Label tests as exploratory simulations; all biological parameters are chosen for contrast, not fitted to synaptic recordings. Report failures. External writing is independent, the controller's own pings actively disturb the route state. No claim about apical tuft decision-making, subjective understanding, or a biological neural address code.
